# HDAFA — Hyper-Deterministic Atomic Agentic Architecture

> **A self-managing software factory built from specialized AI agents with deterministic verification.**

## 🎯 Overview

HDAFA is a multi-agent architecture that transforms natural language descriptions into verifiable HTML/CSS output through three specialized agents:

1. **Requirements Analysis** → JSON Schema
2. **Code Generation** → HTML/CSS
3. **Deterministic Verification** → automated checks (no AI)

**Core Hypothesis:**
> Structure + Deterministic Verification = More Reliable Output

## 🏗️ Components

| Agent | Role | Output |
|-------|------|--------|
| **Requirements Analyzer** | Parses description | JSON Schema |
| **HTML/CSS Coder** | Generates code | HTML page |
| **Validator** | 15 deterministic checks | PASS/FAIL report |

## 🛠️ Tech Stack

- **Python 3.12**
- **Gemini API** (gemini-3.5-flash-lite)
- **Regex + JSON** for deterministic validation
- **Google Colab** runtime

## 📚 Design Principles

HDAFA follows 6 governing principles:

1. **Hyper-Atomicity** — Each agent handles one task
2. **Deterministic Outer Shell** — Verification is automated, not opinion-based
3. **Ephemeral Agents** — No shared state between agents
4. **Closed-Loop Verification** — Nothing passes without validation
5. **Dynamic Specialization** — A dedicated agent for each task
6. **Intelligence Stratification** — Different models for different layers
